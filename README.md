# nonebot-plugin-fishslang 🐟

> 群聊黑话词典：**全局一份 + 每个群一份**，两级合并后只把「这个群此刻用得上」的几条注入提示词。
> **零 LLM 开销** —— 纯查表。

从跑了半年的 QQ 机器人（[肥鱼人设](https://github.com/173ababah)）里拆出来的黑话模块。

## 为什么需要它

模型不懂「答辩=大便」「绷不住了=笑死」这种群内语。全塞进去又太贵、也太吵，
所以只给**当前群 + 最近聊天里出现过的**那几条，长度硬上限 600 字。

## 命令

| 命令 | 说明 |
|------|------|
| `/黑话` | 看本群生效的黑话（标注来源：全局 / 本群） |
| `/黑话 加 答辩 大便` | 加到本群 |
| `/黑话 删 答辩` | 从本群删 |
| `/黑话 全局 加 绷不住了 笑死` | 加到全局（所有群都认） |

默认只有超管能用（`on_command(..., permission=SUPERUSER)`）。私聊里只允许改全局。

## 给别的插件用

```python
from nonebot_plugin_fishslang import slang_block

block = slang_block(session_id, recent_text)   # session_id 形如 group_123456
if block:
    system_prompt += "\n" + block
```

输出形如：

```
【这个群的黑话（群里懂、外面不懂；你自己知道意思就行，别解释、别问）】答辩=大便；绷不住了=笑死；老六=阴人
```

## 三条设计取舍

### 1. 全局 + 本群两级，同名词本群优先

```json
{"*": {"答辩": "大便"}, "123456": {"答辩": "本群另有说法"}}
```

用户的原话是「并且还需要全局的黑话」—— 全局那份所有群都认，
群自己那份用来**覆盖/补充**，不用每个群重复抄一遍。

### 2. 注入按「最近聊天命中」加权

`rank()` 先挑最近聊天里出现过的词（按**子串**判定，所以「绷」在「绷不住了」里也算命中），
再按词长排序（长的更具体），最后按 `max_chars` 截断。

这样同一个群聊八卦时注入的是八卦相关的词，聊游戏时是游戏相关的词 —— 而不是一本词典。

### 3. mtime 热读

控制台/别的进程改完 `slang.json` 立刻生效，不用重启 bot。缓存键就是文件 mtime。

## 文件格式

```json
{
  "*":        {"答辩": "大便", "绷不住了": "笑死"},
  "123456":   {"老六": "阴人"}
}
```
